# Store assets

Screenshots for the Chrome Web Store listing — see the repo README's
"Publishing to the Chrome Web Store" section for context.

- `popup.png` — the extension popup, all toggles on. Good as-is for the
  listing.
- `youtube-search.png` — logged-out search results for "news" with 0
  visible `/shorts/` links. Good as-is for the listing.
- `youtube-watch.png` — logged-out watch page with 0 visible `/shorts/`
  links in up-next and the Autoplay toggle fully hidden. Good as-is for
  the listing.
- `youtube-home.png` — signed-in home feed, dark theme, no Shorts shelf
  and no Mixes shelf anywhere in the grid or filter chips. Cropped from
  a 2552x1332 source to the store's required 1280x800 (16:10) ratio;
  the crop was centered, which trims the YouTube logo and account icons
  off the top edges. Still clearly reads as YouTube and clearly shows
  the blocking working — usable as-is. A left-aligned crop that keeps
  the logo would look cleaner if this ever gets redone from a fresh
  screenshot.

All four are ready to upload for submission.
